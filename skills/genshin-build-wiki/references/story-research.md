# 人物故事 / 剧情考据检索

用于回答**人物故事、角色故事、剧情考据**，以及魔神任务 / 传说任务链的来龙去脉。这类问题跨越多个大版本、官方页面众多，按 `SKILL.md` 的「大跨度剧情 / 考据检索」执行：**先建索引、沿内链织网、跨语言核对、证据分级、覆盖透明**。剧情事实以 BWiki（必要时 OBC）和游戏文本为核心；名称词源、译名差异与文化原型可补充多语言资料，知乎或 Reddit 只作为社区考据线索。

## 一、全文搜索入口

BWiki 使用 MediaWiki 的全文搜索（full-text search）。关键词必须 **URL 编码**（URL-encode），中文尤其如此。请求形如：

```
https://searchwiki.biligame.com/ys/index.php?search=<kw>&go=前往
```

- `<kw>`：把关键词做 URL 编码后拼入 `search=`，例如「桑多涅」→ `%E6%A1%91%E5%A4%9A%E6%B6%85`。
- **分页**：结果不止一页时沿页面返回的 `offset` 链接翻页，或点结果页底部「后 20 个 / 下一页」，直到没有新命中。不要猜测分页 URL，优先复用页面给出的完整链接。
- 也可先用 BWiki `api.php` 的 `opensearch` 拿标题候选，再用 `searchwiki.biligame.com` 做全文命中，两者互补。

## 二、页面类型与权威度

命中后先看条目属于哪类，据此判断它对「剧情事实」的权威程度：

| 页面类型 | 内容 | 对剧情考据的作用 |
|----------|------|------------------|
| 魔神任务 | 主线剧情 | 世界观与主线事实的最高权威 |
| 传说任务 | 角色个人故事线 | 角色故事的核心来源 |
| 世界任务 | 区域支线剧情 | 补全地区背景与因果 |
| 邀约任务 | 角色邀约事件 | 角色性格与关系细节 |
| 活动任务 | 版本活动剧情 | 时效性剧情，注意标注版本 |
| 物品描述 | 圣遗物 / 武器 / 材料等文案 | 埋线与考据的重要旁证 |

角色页、剧情页正文里的引用与「相关词条」也是织网的入口。

## 三、检索流程

1. **建索引**：对主题关键词、别名、相关角色/地点分别全文搜索，把搜索结果列表当作**候选线索**清单（标题 + URL），先不读正文。搜索结果翻页至没有新命中为止。
2. **定向深读**：再逐条打开命中的具体条目页面，读取正文，按上表判断类型与权威度。
3. **沿内链织网**：把正文里与主题**强相关**的内链（前置/后续任务、相关角色、关键地点与事件、相关物品描述）加入待访问清单，逐层扩展至主题闭环；维护「已访问」集合去重，只追强相关链接，不无差别爬全站。
4. **按时间线组织**：以版本 / 因果顺序为骨架串联证据，不平铺堆料。

## 四、多语言名称与文化原型

当用户询问名称含义、隐喻、神话 / 文学 / 宗教借鉴，或中文译名难以看出构词时，增加跨语言核对：

| 来源 | 入口 | 用途 |
|------|------|------|
| Genshin Impact Wiki（英文） | https://genshin-impact.fandom.com/wiki/Genshin_Impact_Wiki | 查看 `Etymology`、`Trivia`、`Historical References`、`Other Languages` |
| Genshin Impact Wiki（俄语） | https://genshin-impact.fandom.com/ru/wiki/Genshin_Impact_%D0%92%D0%B8%D0%BA%D0%B8 | 核对俄语译名、音译词根和斯拉夫文化相关条目 |
| Project Amber（英文） | https://ambr.top/en/archive | 对照任务、书籍、物品与角色的英文游戏文本 |
| Project Amber（俄语） | https://ambr.top/ru/archive | 对照同一条目的俄文游戏文本 |
| r/Genshin_Lore | https://www.reddit.com/r/Genshin_Lore/ | 查找英语社区的词源与文化原型讨论，仅作线索 |

英文、俄文通常是**本地化文本，不是创作意义上的原文或源文本**；原神的源文本通常是中文。跨语言版本的价值是保留德语、拉丁语、希腊语、俄语等外来词拼写，帮助识别中文意译中不明显的双关、词根和现实原型。

1. 先从 BWiki / OBC 确定中文条目和剧情上下文。
2. 在 Project Amber 对照同一游戏文本的中文、英语、俄语名称与描述。
3. 在英文 Wiki 读取对应页面的 `Etymology`、`Historical References` 与 `Other Languages`；网页受验证页阻挡时，使用其公开 MediaWiki API 读取 `sections` / `wikitext`。
4. 涉及俄语或斯拉夫文化时，再检查俄语 Wiki / 俄语游戏文本；不要因某种译名更接近现实词汇，就反推它必然是官方创作原型。
5. 若需要社区论证，按 [social-platforms.md](social-platforms.md) 读取知乎具体回答或 r/Genshin_Lore 帖子，并继续寻找现实历史、语言学、神话或文学资料复核。

游戏文本能够确认名称拼写和剧情事实；词源字典、历史人物与文学作品可确认语言或历史对应；Wiki 的 Etymology / Historical References 与社区讨论属于整理或分析。必须区分**明确事实 / 直接证据**、可验证的**词源或文化原型对应**，以及尚无官方确认的**社区推测 / 玩家推测**。

## 五、证据分级与引用

- 务必区分**明确事实**与基于线索的**合理推断**：正文直接陈述的记为事实；由物品描述、跨语言构词、暗示或玩家解读得出的记为推测，并标明依据。
- 引用只列**实际读取过**的页面，给出标题与完整 URL，能取到更新时间就一并写。
- 多语言结论列出实际比较过的语言与名称；不要写成“外语原文证明”，应写“英语 / 俄语本地化保留了某词根”。
- 知乎和 Reddit 内容按作者分别归因；一篇高赞回答或热门帖子也不等于官方确认或社区共识。
- **覆盖透明**：结尾标注已覆盖的版本 / 章节范围与页数；未展开或未查到的部分如实说明，不把局部当全貌，也不用记忆补全缺口。

## 六、失败处理

- 全文搜索无命中：换别名、拆分关键词或改用 `opensearch` 重试，仍无果则如实说明未在 BWiki 查到。
- 页面正文无法解析：记录失败并回退到该条目的 OBC 对应页或相关词条。
- 普通剧情梗概不查社交平台；只有词源、隐喻、文化原型或用户明确要求社区考据时，才选择性查知乎 / Reddit，并标为社区分析线索。
