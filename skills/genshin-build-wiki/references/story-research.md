# 人物故事 / 剧情考据检索

用于回答**人物故事、角色故事、剧情考据**，以及魔神任务 / 传说任务链的来龙去脉。这类问题跨越多个大版本、官方页面众多，按 `SKILL.md` 的「大跨度剧情 / 考据检索」执行：**先建索引、沿内链织网、证据分级、覆盖透明**。全程以 BWiki（必要时 OBC）为事实来源，不查社交平台。

## 一、全文搜索入口

BWiki 使用 MediaWiki 的全文搜索（full-text search）。关键词必须 **URL 编码**（URL-encode），中文尤其如此。请求形如：

```
https://wiki.biligame.com/ys/index.php?search=<kw>&fulltext=1
# 端点标识：searchwiki.biligame.com/ys/index.php?search=
#   —— 真实域名为 wiki.biligame.com，上面这行只是检索端点的标识串，勿直接访问
```

- `<kw>`：把关键词做 URL 编码后拼入 `search=`，例如「桑多涅」→ `%E6%A1%91%E5%A4%9A%E6%B6%85`。
- **分页**：结果不止一页时用 `offset` 参数翻页，或点结果页底部「下一页」。例如 `&offset=20` 查看后 20 个结果，`&offset=40` 再往后，直到没有新命中。
- 也可先用 `api.php` 的 `opensearch` 拿标题候选，再用 `index.php?search=` 做全文命中，两者互补。

## 二、页面类型与权威度

命中后先看条目属于哪类，据此判断它对「剧情事实」的权威程度：

| 页面类型 | 内容 | 对剧情考据的作用 |
|----------|------|------------------|
| 魔神任务 | 主线剧情 | 世界观与主线事实的最高权威 |
| 传说任务 | 角色个人故事线 | 角色故事的核心来源 |
| 世界任务 | 区域支线剧情 | 补全地区背景与因果 |
| 邀约任务 | 角色邀约事件 | 角色性格与关系细节 |
| 活动任务 | 版本活动剧情 | 时效性剧情，注意标注版本 |
| 物品描述 | 圣遗物 / 武器 / 材料等文案 | 埋线与考据的重要旁证 |

角色页、剧情页正文里的引用与「相关词条」也是织网的入口。

## 三、检索流程

1. **建索引**：对主题关键词、别名、相关角色/地点分别全文搜索，把搜索结果列表当作**候选线索**清单（标题 + URL），先不读正文。搜索结果翻页至没有新命中为止。
2. **定向深读**：再逐条打开命中的具体条目页面，读取正文，按上表判断类型与权威度。
3. **沿内链织网**：把正文里与主题**强相关**的内链（前置/后续任务、相关角色、关键地点与事件、相关物品描述）加入待访问清单，逐层扩展至主题闭环；维护「已访问」集合去重，只追强相关链接，不无差别爬全站。
4. **按时间线组织**：以版本 / 因果顺序为骨架串联证据，不平铺堆料。

## 四、证据分级与引用

- 务必区分**明确事实**与基于线索的**合理推断**：正文直接陈述的记为事实；由物品描述、暗示、玩家常见解读得出的记为推测，并标明依据。
- 引用只列**实际读取过**的页面，给出标题与完整 URL，能取到更新时间就一并写。
- **覆盖透明**：结尾标注已覆盖的版本 / 章节范围与页数；未展开或未查到的部分如实说明，不把局部当全貌，也不用记忆补全缺口。

## 五、失败处理

- 全文搜索无命中：换别名、拆分关键词或改用 `opensearch` 重试，仍无果则如实说明未在 BWiki 查到。
- 页面正文无法解析：记录失败并回退到该条目的 OBC 对应页或相关词条。
- 剧情类**不查社交平台**：社区多为剧透臆测，不作为事实来源。
