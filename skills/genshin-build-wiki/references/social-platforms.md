# 社交平台查询指南

本文档说明如何使用 OpenCLI 查询社交平台（小红书/知乎/B站）来获取社区实战反馈。

## 小红书（Xiaohongshu）

### 常用命令

```bash
# 搜索笔记
opencli xiaohongshu search "胡桃配装" -f json

# 获取笔记详情
opencli xiaohongshu note "note_id" -f json

# 获取用户笔记
opencli xiaohongshu user "user_id" -f json
```

### 查询策略

1. **关键词构建**：`角色名 + 配装/圣遗物/武器/配队`
   - 例：`胡桃配装`、`那维莱特圣遗物`、`芙宁娜武器推荐`

2. **筛选原则**：
   - 优先高赞笔记（点赞数 > 1000）
   - 选择近期发布（3 个月内，版本适配性）
   - 关注标题包含版本号或深渊期数的内容

3. **提取重点**：
   - 实战充能体验
   - 零氪/低氪平替方案
   - 新手常见误区
   - 深渊通关配队

4. **标注来源**：
   ```markdown
   - **小红书：** [笔记标题](URL) - 👍 1.2k / 📅 2026-07-15
   ```

### 注意事项

- ⚠️ 内容质量参差不齐，需人工筛选
- ⚠️ 避免营销号/引战内容
- ⚠️ 明确标注为「社区分享」，与官方数据区分
- ⚠️ 若搜索失败或无有价值内容，可跳过该平台

## 知乎（Zhihu）

### 常用命令

```bash
# 搜索问题/文章
opencli zhihu search "那维莱特圣遗物" -f json

# 获取问题详情和回答
opencli zhihu question "question_id" -f json

# 获取热榜
opencli zhihu hot -f json
```

### 查询策略

1. **关键词构建**：
   - 问题式：`如何给胡桃配装`、`那维莱特用什么圣遗物`
   - 对比式：`胡桃用魔女还是追忆`、`草神精通堆多少`

2. **筛选原则**：
   - 优先高赞回答（赞同数 > 500）
   - 关注专业玩家/数据分析类回答
   - 注意回答时间与版本适配

3. **提取重点**：
   - 配装机制深度分析
   - 不同流派对比
   - 充能/精通/暴击等数值建议
   - 版本变化影响

4. **标注来源**：
   ```markdown
   - **知乎：** [问题/回答标题](URL) - 👍 2.3k / 📅 2026-06-20
   ```

### 注意事项

- ⚠️ 知乎内容较知乎，但也有争议性讨论
- ⚠️ 优先选择有数据支撑的回答
- ⚠️ 避免情绪化/争议性内容
- ⚠️ 标注为「社区讨论」

## B站视频（Bilibili）

### 常用命令

```bash
# 搜索视频（使用 OpenCLI）
opencli bilibili search "芙宁娜配装攻略" --limit 5 -f json

# 获取视频详情
opencli bilibili video "BV号" -f json

# 获取字幕
opencli bilibili subtitle "BV号" -f json
```

### 参数说明

- `--limit <number>`: 返回结果数量（默认 20）
- `--type <video|user>`: 搜索类型（默认 video）
- `--page <number>`: 结果页码（默认 1）
- `-f, --format <fmt>`: 输出格式（json/yaml/table/csv）

### 查询策略

1. **关键词构建**：`角色名 + 配装攻略/深渊/实战测试`
   - 例：`胡桃配装攻略`、`那维莱特深渊实战`

2. **筛选原则**：
   - 播放量 > 10w
   - UP主为知名攻略区 UP（如：xxx、yyy）
   - 发布时间近期（1 个月内）

3. **使用方式**：
   - **仅提供视频链接**，不强制提取字幕（避免过重）
   - 标注视频标题、UP主、播放量、发布时间
   - 让用户自己观看详细攻略

4. **标注来源**：
   ```markdown
   - **B站视频：** [视频标题](URL) - 📺 15.2w播放 / 📅 2026-07-10 / UP主: XXX
   ```

### 注意事项

- ⚠️ 视频攻略参考为主，不作为唯一依据
- ⚠️ 避免标题党/震惊体视频
- ⚠️ 标注为「视频攻略参考」
- ✅ 使用 OpenCLI 的 `bilibili` 子命令，无需单独安装 bili-cli

## 综合使用建议

### 并行查询

官方数据与社区讨论应**并行查询**，不要等官方查完再查社区：

```bash
# 并行执行
curl -s "https://r.jina.ai/https://wiki.biligame.com/ys/胡桃" &
opencli xiaohongshu search "胡桃配装" -f json &
opencli zhihu search "胡桃圣遗物" -f json &
opencli bilibili search "胡桃配装攻略" -f json &
wait
```

### 失败处理

- 某个平台失败不影响其他平台
- 若所有社区平台都失败，可仅用官方数据回答
- 明确告知用户哪些平台查询成功/失败

### 内容融合

1. **官方数据为主**：数值、套装效果、基础推荐来自 BWiki + OBC
2. **社区补充**：实战体验、平替方案、注意事项来自社交平台
3. **派蒙综合**：结合两者给出平衡建议
