# Paimon Desktop 目标说明

## 目标

构建一个基于 Tauri 2 的 Windows 桌面应用。用户打开 EXE 后可以直接提问，不需要额外喊出派蒙或安装外部 Agent。应用支持配置大模型、连续多轮对话、Markdown 输出、网页查询与动态页面内容提取，并将实际使用的来源展示给用户。

## 核心决策

### 1. 使用 Tauri 2

应用以 Vue 3 + TypeScript 作为界面，以 Rust 作为模型调用、工具调度、网页请求和本地存储的后端。动态网页使用应用自己的 WebView2 用户数据目录，登录态独立于 Chrome/Edge，并在应用重启后持久化。

### 2. 系统提示词可配置

系统提示词不是写死在 Rust 或前端代码中的常量。默认提示词由应用资源文件提供，首次启动时导入本地配置；用户可在设置页编辑、保存、导出、恢复默认值。

最终发给模型的规则由以下部分按顺序组合：

```text
用户配置的基础系统提示词
+ 用户配置的角色/语气提示词
+ 启用的领域规则资源（默认包含 genshin-build-wiki/SKILL.md）
+ 应用运行时工具说明
+ 当前会话级提示词（可选）
```

工具的参数、权限和执行逻辑仍然属于程序代码；提示词只描述使用原则和回答规则，不承担网页操作实现。

### 3. Skill 作为可复用规则资源

EXE 不要求用户安装外部 Skill。打包时将现有 `skills/genshin-build-wiki/` 作为只读默认资源带入应用；应用启动时读取它并允许用户选择是否启用。仓库中的 `SKILL.md` 继续是规则正文的权威来源，桌面端不复制一份硬编码版本。

### 4. 网页查询分层

- BWiki、OBC、普通静态网页：优先由 Rust `reqwest` 获取并清洗。
- 需要登录或动态加载的网页：由应用 WebView2 打开，复用持久化登录态。
- 评论、展开更多、切换分页和滚动加载：先提供通用浏览器操作，再为高频平台编写适配器。
- 不做验证码绕过、自动发布、点赞、删除或提交表单等有外部副作用的操作。

### 5. 第一版只支持 OpenAI-Compatible 模型接口

通过 Base URL、API Key 和 Model ID 接入 DeepSeek、中转站、Ollama、LM Studio、vLLM 等服务。设置页测试基础请求、流式输出和工具调用能力，并分别显示结果。

## 成功标准

- 打开应用后可以直接新建对话并连续提问。
- 设置页可以新增、编辑、删除和测试模型连接。
- 设置页可以编辑最终系统提示词相关配置，并支持保存与恢复默认值。
- 应用可以安全渲染模型返回的 Markdown。
- 应用可以查询 BWiki/OBC，并在回答中展示实际来源。
- 应用可以打开网页、保持独立登录态、等待动态加载、有限滚动并提取正文或评论。
- 对话、消息、工具执行记录和来源可以本地保存。
- 模型、网页、工具失败时，界面能明确显示失败原因，不用模型记忆伪装成实时查询。
- Windows 构建能生成可安装 EXE，并保留应用数据和 WebView 登录目录。

## 非目标

- 不把应用做成完整浏览器替代品。
- 不支持任意网站的无规则全自动点击保证。
- 不将 Cookie 导出给模型或写入项目数据库。
- 不在首版实现大规模并发爬取、验证码处理和社区平台的所有页面类型。
- 不要求用户在任意目录安装或链接外部 Skill。

## 主要风险与处理

| 风险 | 处理 |
|---|---|
| 网站 DOM 改版 | 通用提取作为回退；高频网站适配器单独测试和版本化 |
| 登录失效或验证码 | 停止自动任务，提示用户在应用 WebView 中接管 |
| 网页 Prompt Injection | 网页内容标记为不可信数据，不能覆盖系统提示词或扩大工具权限 |
| 模型不支持 Tool Calling | 设置页标注能力；允许普通聊天，联网工具默认不可用 |
| 长对话超出上下文 | 保留近期消息，旧消息摘要化，工具正文按长度和相关性裁剪 |
| SSRF 和恶意 URL | Rust 侧限制协议、内网地址、重定向次数、响应大小和超时 |

## 交付顺序

1. Tauri 2 应用骨架、设置存储和可编辑提示词。
2. OpenAI-Compatible Provider、连接测试和流式聊天。
3. SQLite 会话、消息、工具记录和来源存储。
4. Markdown 安全渲染和桌面聊天界面。
5. BWiki/OBC/普通网页工具。
6. WebView2 登录态、网页标签、动态滚动和正文提取。
7. 评论与高频社区网站适配器。
8. Windows 安装包、回归测试和隐私/数据清理设置。
