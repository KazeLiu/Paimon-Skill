# 设置中的采集测试

## 目标与验收

- 设置新增「采集测试」，输入 B站视频、小红书笔记、知乎回答或文章详情 URL。
- 复用正式 `research_source_with_visual`、平台 Adapter 和 `TauriBrowserExecutor`；不添加抓取回退或修复既有读取问题。
- B站检查字幕、评论、播放量；小红书和知乎检查正文、评论、图片。
- 展示已返回、未取得、失败，保留步骤耗时、正式报告、原始步骤结果及错误，可复制脱敏 JSON。
- 不调用模型分析，不写聊天历史，不保存测试地址和结果；仅在当前应用会话内保留。

## 模块

- `src-tauri/src/source_tests.rs`：详情 URL 校验、正式路径调用、旁路步骤记录、结果摘要和 Tauri 命令。
- `src/types/sourceTests.ts`、`src/api/sourceTests.ts`、`src/stores/sourceTestStore.ts`：类型、调用与测试期间状态。
- `src/pages/SourceTestSettingsPage.vue`：平台切换、地址表单、字段检查、图片预览、步骤与原始结果。
- `src/App.vue`、`src-tauri/src/lib.rs`：设置导航和命令注册。

## 执行清单

- [x] 后端：实现只读观测包装，返回真实步骤和报告；错误保留，测试窗口按所有权关闭。
- [x] 前端：新增设置页，保留各平台输入与结果，防止重复提交，显示失败与图片预览状态。
- [x] 验证：平台路由、空评论和字幕错误、元数据与图片缺失、脱敏、正式 Adapter 调用、页面导航和复制。
- [x] 交付：构建并重启客户端，记录验证范围与已知读取缺口。

验证结果：173 项 Rust 测试通过（另一个需模型凭据的在线用例按默认忽略），84 项前端测试通过，Vue 类型检查与构建通过。真实桌面端通过设置页调用 `run_source_test`，B站实测保留了 `missing field version` 的既有字幕错误，评论与播放量标为未取得，测试前后聊天历史和网页数量一致。1211px 和 920px 视口检查无横向溢出。小红书、知乎覆盖正式路由、适配器结果和 UI 回归，本次未用真实链接联网实测。

## 失败与验证

错误不会自动启动另一套查询方案。未取得图片 URL 与预览加载失败分开显示；没有评论时不能因返回了报告头部而标记成功。字幕工具返回 `{}` 时保留该原始结果和正式解析错误。

运行针对性的 Rust / Vitest 测试、Vue 类型检查与构建；用真实桌面端确认新入口可用。平台联网结果依赖用户链接、登录态与网站状态，测试页如实展示，不承诺读取成功。前端浏览器预览如使用模拟数据，仅用于视觉 QA。

## 已决定

用户选择「只增加测试页，如实展示结果和失败原因」。没有其他必须确认的事项。代码提交与推送按用户后续授权执行。
