# 研究编排阶段 3：小红书与在线视觉实现计划

> **计划状态：待用户审阅。** 执行阶段必须先完整读取本文件，再实现或审计已有改动；所有隐私和降级测试均为必测项。

## 执行目标

将小红书从 Generic 包装器升级为笔记详情适配器，结构化提取正文、作者、时间、互动数据和轮播图片，并通过平台无关的在线视觉任务接口识别攻略图片；正文、视觉结果和评论必须分离。

## 目标与验收标准

- 只接受具体笔记详情；搜索页仅发现候选。
- 保留 `NOTE_URL` 中访问详情所必需的查询参数（包括 `xsec_token`），但不得记录 Cookie 或把 Cookie 交给模型。
- 提取标题、正文、作者、发布时间和可见互动数据；缺失字段明确 warning。
- 提取并去重轮播图片 URL/资源句柄，不在模型上下文暴露认证头或 Cookie。
- 建立在线视觉模型任务 trait；只有存在图片且用户问题需要图片内容时才调用。
- 视觉结果覆盖 OCR、表格、角色面板、圣遗物、武器、配队和攻略步骤等可观察内容，不把推断冒充页面事实。
- 用户要求评论/口碑时读取评论；Body、Visual、Comments 三类 artifact 独立保存。
- 登录、验证码、风控、图片不可访问、视觉模型不支持和取消均可明确降级并清理资源。

## 范围 / 非目标

范围：小红书详情、轮播图片、在线视觉抽象与现有大模型多模态能力桥接、评论分离。

非目标：下载原图到长期存储、绕过防盗链/风控、图像生成、本地 OCR/视觉模型、B站关键帧。

## 现状与关键约束

- `XiaohongshuAdapter` 当前仅调用 Generic adapter。
- `ResearchReport.visual` 和 `KeyFrameRequest` 只有骨架，尚无真正的模型任务执行器。
- 现有模型供应商已经支持部分多模态消息，但需要明确能力探测和错误边界。
- 页面与图片是非可信输入；Cookie、签名头、完整隐私凭据不能进入日志或模型上下文。

## 文件和模块职责

- `research/adapters/xiaohongshu.rs`：笔记详情编排、字段和 artifact 组装。
- `research/model_tasks.rs`：平台无关 `ModelTaskExecutor`/视觉请求与结果契约。
- `research/models.rs`：Visual artifact 和必要的非敏感媒体引用。
- `browser/scripts.rs`：笔记字段与轮播图片的有界提取。
- `research/tauri_executor.rs`：桌面网页/图片获取桥，不持有视觉供应商业务规则。
- `providers/*`：复用现有在线模型协议与能力标记；必要时增加视觉能力探测。
- 设置页面仅在现有模型配置不足以选择视觉模型时做最小扩展，不新增独立落地页。

## 任务清单

1. 写详情 URL、必要查询参数保留和搜索页拒绝测试。
2. 定义笔记正文、图片列表和视觉请求的共享数据契约及上限。
3. 实现标题、正文、作者、时间、互动数据、轮播图片的结构化提取。
4. 建立在线视觉任务 trait 和 Tauri/模型供应商桥接；明确不支持视觉时的降级结果。
5. 定义“需要视觉”的意图判定，避免所有笔记无条件发送图片。
6. 逐张或分批分析图片，控制张数、像素/字节和上下文大小，合并为独立 Visual artifact。
7. 按 `wants_comments` 读取评论并保持三类 artifact 分离。
8. 覆盖登录/验证码、图片失效、模型拒绝、取消和临时资源清理。
9. 执行定向与全量验证。

## 验证矩阵

- URL：详情通过、搜索页拒绝、必要 query 保留、无关追踪参数可规范化。
- 字段：固定 fixture 提取标题、正文、作者、时间、互动数据和多张轮播图。
- 视觉条件：不需要图片时视觉 executor 调用次数为 0；需要时进入视觉流程。
- 视觉结果：Visual artifact 独立存在，不覆盖 Body/Comments；图片数量和内容长度受限。
- 评论条件：未要求评论不调用；要求时评论独立保存。
- 隐私：测试注入 `Cookie`、`Authorization`、`xsec_token` 等敏感样例，日志和模型请求中不得出现 Cookie/Authorization；必要详情 token 只用于本地页面访问，不进入研究正文。
- 阻断：登录、验证码、风控不会返回成功正文；视觉不可用时正文仍可带 warning 返回。
- 清理：成功、失败、取消路径清理临时图片/窗口。
- 回归命令：

## 完成标准和停止条件

- 字段、轮播图片、按需视觉、评论分离和隐私测试全部有直接证据后才能完成阶段 3。
- 若现有模型供应商没有可靠视觉协议，必须返回“视觉能力未配置”，不得把接口伪装为已接通。
- 若图片只能通过绕过风控取得，停止图片流程并保留正文降级结果。

## 当前实现备注

当前工作区已有小红书字段提取、图片引用限制、视觉任务抽象和按需调用逻辑。阶段执行仍需复跑本文件验证矩阵，特别是敏感 URL、Cookie/Authorization 脱敏、视觉调用次数和失败清理；未通过前不得将阶段标记为完成。

## 风险、失败处理与回退

- 图片 URL 可能短期有效：仅在任务内使用，禁止长期缓存和日志输出完整签名 URL。
- 多图成本和上下文膨胀：按问题选择相关图片并设置硬上限。
- 可回退为正文+评论报告，并明确本次未覆盖图片内容。
