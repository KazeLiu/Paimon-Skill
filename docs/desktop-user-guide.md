# 派蒙助手桌面端使用与隐私说明

本文说明 `apps/desktop/` 生成的 Tauri 2 Windows 应用在本机保存哪些数据，以及网页查询的边界。

## 首次使用

1. 打开应用后进入「设置 → 模型」，填写 OpenAI-Compatible Base URL、模型 ID 和 API Key。
2. 点击「测试连接」确认基础请求、流式输出和工具调用能力，再保存配置。
3. 回到主页新建对话即可连续提问。系统提示词和内置规则可以在「设置 → 系统提示词」中编辑或关闭。
4. 需要登录的网站从「浏览网页」打开。登录是在应用自己的 WebView2 页面中完成，与 Chrome/Edge 的登录态相互独立。

## 本地数据

应用数据由 Tauri 的路径 API 决定，安装目录不会保存会话数据。Windows 上通常位于以下目录（具体根目录以系统用户和 Tauri 标识为准）：

| 数据 | 用途 |
| --- | --- |
| 应用数据目录/`paimon.db` | 对话、消息、工具执行记录、来源 URL |
| 应用配置目录/`providers.json` | 模型连接参数和 secret 引用，不含 API Key |
| 应用配置目录/`prompt-settings.json` | 系统提示词的开关、覆盖和自定义补充规则 |
| 应用本地数据目录/`browser-profiles/default` | 应用内 WebView2 的 Cookie、Local Storage 和缓存，用于保留网页登录态 |

API Key 只写入 Windows 系统凭据库，服务名为 `io.github.kazeliu.paimon-desktop`。API Key 不会写入 SQLite、JSON 配置、工具记录、日志或发送给模型上下文。删除模型配置时会同步删除对应系统凭据。

删除某个对话会级联删除该对话的消息、工具记录和来源。应用不会把 Cookie 或 Local Storage 导出给模型，也不会写入项目仓库。

## 清理网页登录态

进入「设置 → 隐私与数据」，点击「清理登录态」并确认。应用会先关闭应用内网页标签，再删除 `browser-profiles/default`，因此下次访问网站需要重新登录；系统浏览器的 Cookie 不受影响。该操作只针对固定的应用 Profile 目录，不会删除应用数据库或其他用户文件。

## 网页查询边界

- 支持打开 HTTP/HTTPS 页面、读取可见正文、有限滚动、展开评论等只读操作，并将实际来源显示在查询活动中。
- 页面内容被视为不可信数据，不能覆盖系统提示词或扩大工具权限。
- 不承诺任意网站都能稳定适配，不绕过验证码，也不自动执行登录、发布、点赞、删除、下载或表单提交。
- 页面要求登录或出现验证码时，自动任务会停止，用户可以在应用 WebView 中完成接管后重试。
- 动态网站的 DOM 变化可能导致通用提取失败；高频社区网站使用有限的适配器，失败时会明确提示，不用模型记忆冒充实时查询。

## 卸载与备份

NSIS 卸载程序主要移除应用安装文件。应用数据目录和 WebView2 Profile 通常保留，以便重新安装后恢复对话和登录态；如需彻底删除，请先在应用内清理网页登录态，再手动删除 Tauri 应用数据和配置目录。删除前请确认路径只属于派蒙助手，避免误删其他应用数据。
