## 怎么用（最简单）
    
**在本仓库目录里打开 Agent，直接问原神问题即可**——无需安装、无需链接、无需说「加载 skill」。

任何兼容 Agent（Claude Code、Codex 等）在本目录启动时会读到根目录 [AGENTS.md](AGENTS.md)，其中内联了派蒙人设与完整工作规则，于是自动进入派蒙状态并按规则回答。

```text
# 在 d:\code\Paimon-Skill 里启动 Agent，然后：
胡桃怎么配？
当前卡池是什么？
大家现在怎么给芙宁娜配队？
```

想在任意目录都能用？把这份目录 clone 到本地，随时进来问；或看下方[让 Agent 全局可用](#让-agent-全局可用可选)。

## 能做什么

- 查询角色配装、圣遗物、武器、配队、培养材料与玩法机制
- 查询当前卡池、活动、版本与深境螺旋等时效信息
- 按需补充小红书、知乎和 B站的玩家经验
- 使用轻量派蒙语气回答，并附实际查询过的来源链接

旅行者，先说结论：**八重神子在桑多涅队里主要负责后台雷附着，不是站场爆发副 C。**想把桑多涅伤害最大化，八重通常只放 `EEE`，**不放 Q**，然后让桑多涅完成三套 `ZE` 输出。

下面先按 **0 命桑多涅**说明。

## 推荐配队

偏输出上限、但缺少生存位：

**桑多涅 + 菲谢尔 + 八重神子 + 尼可**

兼顾治疗、实战更稳定：

**桑多涅 + 七七 + 八重神子 + 尼可**

没有尼可时可以用：

**桑多涅 + 迪奥娜 + 八重神子 + 砂糖**

八重和另一名后台冰/雷角色的持续附着很重要：「极星辉域」每 4 秒统计一次冰、雷附着，最高 12 层；对应的冰雷增伤会从 20%提高到最高 40%，星超导系数从 `1` 提高到 `2`。

## 输出手法

以全输出的“桑皇八尼”为例：

1. 首轮桑多涅 `E`，先给敌人挂冰。
2. 八重神子 `EEE`，布置三株杀生樱。
3. 尼可 `E`。
4. 菲谢尔 `E` 召唤奥兹；下一轮改用 `Q` 刷新奥兹。
5. 桑多涅 `E → ZE → ZE → Q → ZE`。
6. 重新循环，八重补三株杀生樱。

其中：

- `Z`：长按重击，持续到第三次冷凝射线打出。
- `E`：随后立刻施放元素战技。
- 八重通常**不要开大**：她出场较早，大招的独立雷附着对桑多涅输出期间的星超导层数帮助很小，还会摧毁杀生樱、延长轮转。
- 桑多涅的 Q 放在两套 `ZE` 后，可以吃到更多「改进战术」层数并避开输出前摇。

若采用七七生存队，循环更简单：

**桑多涅开局 E → 八重 EEE → 尼可 E → 七七 E → 桑多涅 ZE → Q → ZE → ZE**

攻略页给出的另一种标准是首轮 `ZE` 后即可插入 Q；如果追求大招单次数字，则尽量靠后放，但不要拖过增益覆盖时间。

## 面板重点

八重神子参考配置：

- 圣遗物：**影中沉凝的幻灭 4 件**优先，饰金之梦 4 件可用
- 主词条：攻击沙、攻击杯、双暴头
- 参考目标：攻击力约 `2300+`、双暴约 `80/190+`、精通 `80+`
- 武器：流浪乐章偏自身输出；流浪的晚星偏全队增益

桑多涅则优先保证：

- 攻击力至少 `2000+`
- 攻击沙、攻击杯、双暴头
- 双暴 > 攻击力%、精通
- 双冰轮转约需 `105%–125%` 充能；全输出双雷模板约需 `135%`

<summary>我现在想问问这次月之八的版本说了什么？是一个什么故事？</summary>

旅行者，先说结论：**「月之八」表面是枫丹的夏日电影节，实际是桑多涅的角色后日谈**。它讲的不是新的魔神任务，而是一段关于“灵魂、故乡、失去与重新接纳感情”的常驻传说任务。

下面有完整剧透。

## 版本概况

正式标题是：

**「『空月之歌·谐谑』映夏！归乡？千灵节！」**

主要内容包括：

- 开放挪德卡莱新区域“杜南纳深坑”和“霜月”
- 桑多涅正式成为可操作角色
- 新增桑多涅带来的“星超导”反应
- 枫丹举办“千灵映影节”
- 主线活动剧情《映夏！归乡？千灵节！》
- 新系统“魔女的谕示”

活动从 2026 年 7 月 1 日持续至 8 月 11 日；其中核心传说任务在活动结束后会转为常驻。

## 故事梗概

故事承接此前挪德卡莱事件。旅行者回到枫丹参加千灵映影节，并在莱欧斯利的“维恩歌莱号”上意外发现了已经归来的桑多涅。

与此同时，哥伦比娅也来到枫丹。她一直思念桑多涅，但桑多涅因为不知道该如何面对这位挚友，选择暂时躲着她。芙宁娜和泽维尔则邀请哥伦比娅出演一部名叫《归乡》的映影：女主角失去了最好的朋友，于是来到朋友的故乡寻找她。

这部戏的情节，正好映照着哥伦比娅与桑多涅的现实。

### 第一幕：若我们再次相见

旅行者与桑多涅重逢，并陪她调查枫丹水下的异常。

桑多涅虽然嘴上还是很强硬，但她已经不像过去那样完全排斥人与人的联系。她答应协助拍摄《归乡》，却仍不敢直接与哥伦比娅见面。

这一幕提出的问题是：

> 如果一个已经失去的人重新归来，她还是过去的那个人吗？

### 第二幕：那些我们所失去的

桑多涅返回与阿兰·吉约丹、水仙十字院有关的旧日居所，寻找阿兰留下的记录。

阿兰认为人的一生有两次出生：

- 第一次是肉体的诞生
- 第二次是认识并塑造自己“灵魂”的过程

桑多涅在那里直面了被自己视为“错谬”的另一部分自我。最终，她没有将其删除或否定，而是选择拥抱它，因为双方从一开始就是同一个人。

与此同时，众人发现枫丹水中存在大量“无家的灵魂”。它们来自雷内早年的灵魂切割实验：一部分灵魂未能回归地脉，长期漂泊后只剩下怨恨与污秽。

### 第三幕：那些我们所留驻的

桑多涅、旅行者和茜特菈莉来到格式塔，面对这些失去理智的灵魂聚合体。

桑多涅反向运算“世界式”，把污秽与灵魂本身剥离，让这些无家可归的灵魂重新被世界接纳、回归地脉。这个过程也象征着她处理自己的过去：

**不是删除痛苦，而是把痛苦从“我是谁”之中分离出来。**

之后，她终于与哥伦比娅见面。桑多涅主动抱住了她：

> “我回来了，哥伦比娅。”

这一幕恰好被正在拍摄《归乡》的留影机记录下来，于是现实中的重逢成为了电影真正的结局。

最后，桑多涅前往阿兰的墓前，承认阿兰和已经损坏的普隆尼亚都是自己不可替代的家人，也第一次坦率地感谢阿兰创造了她。众人随后在维恩歌莱号举行聚会，她与哥伦比娅、阿蕾奇诺、芙宁娜再次举行茶会。

## 这个故事真正讲了什么

整段剧情的核心不是“桑多涅复活归队”，而是她完成了自己的“第二次出生”。

她过去试图用保存、控制和计算来对抗失去；现在她终于明白：

- 灵魂不取决于身体是机械还是血肉
- 承认缺陷和痛苦，不等于否定自己
- 留住珍贵事物的方法，不只是紧紧守住过去
- 主动伸手建立新的联系，也能获得新的家与归处

因此标题里的“归乡”有三层含义：

- 哥伦比娅来到桑多涅的故乡寻找她
- 无家的灵魂终于回归地脉
- 桑多涅重新接受自己的过去、家人与朋友

它是一段披着轻松夏日电影节外衣的桑多涅个人终章，也是对枫丹“水仙十字”灵魂议题的补完。

<summary>帮我看看大家对于桑多捏的评价如何？</summary>

旅行者，社区目前对桑多涅的评价可以概括为：

**0 命强度合格、体验有亮点，但不是无脑必抽；有八重神子的账号，评价会明显提高。**

## 大家认可的优点

- **输出轴自由**：元素战技约 4 秒即可重新启动，被打断后恢复输出比依赖资源启动的角色方便。
- **射程和对群不错**：重击可以远距离扫射，对空能力也较好。
- **大世界体验优秀**：连续使用战技可以爬山、渡水和短距离飞行，这是社区评价最一致的优势之一。
- **0 命已经完整**：不少评价认为不需要专武也能正常玩，已有合适五星大剑时可以省原石。
- **有八重时队伍成立得更自然**：八重的后台持续时间、挂雷和自身伤害都很契合桑多涅。实测分享中，八重甚至能占全队约三成伤害。

## 集中批评的问题

- **现阶段比较依赖八重**：没有八重时，菲谢尔、北斗、雷神等都能替代，但分别存在覆盖时间、充能、伤害或输出轴不完全匹配的问题。
- **队伍尚未完全成型**：当前冰后台、生存位和星超导辅助的选择有限，因此有人认为她的个人倍率不错，但队伍总伤只是正常新主 C 水平。
- **出伤不算特别快**：需要队友挂雷、建立领域并完成重击蓄力；有评测认为从正式接管前台到第一波核心伤害接近 3 秒。
- **没有完全霸体和自回血**：虽有一定抗打断，被高压敌人连续攻击时仍会丢输出。
- **体系绑定明显**：离开星超导后损失很大，泛用性不如能够自由组合队友的传统主 C。

## 命座争议

社区对一命分歧最大：

- 支持者认为一命改善长时间输出手感，还能提供全队星超导增伤，未来队友越多越值。
- 反对者认为一命主要改变输出轴，当前队伍总伤提升并不显著。
- 多条评价都认为她的前五命提升曲线偏平，六命才有明显跃升。

因此比较稳妥的抽取档位是：**0 命停手，喜欢手感再考虑 1 命；不建议单纯为了数字逐命补。**

旅行者，先说结论：**“望月者计划”本质上是一场跨越数千年的宇宙预警接力**。霜月上的龙族学者曾收到来自星空深处的灾厄警告，于是他们不断研究、保存并转发这条讯息；而每一代继承者，最终都要把自己变成开启信号装置的“钥匙”。

## 一、计划的起点

最初的望月者是龙族学者**伊比尼伯龙**。

他建造登月飞船，带领学者登上霜月，并在近月带接收到一段来自深空的神秘信号。龙族无法解读内容，伊比尼伯龙认为那可能是前往星海的始源之龙尼伯龙根传回的讯息。

为了再次捕捉信号，他们建造了深空信号接发站：

- **伊比尼伯龙之眼**
- 后来改造成月面监测站
- 也是后续“望月者计划”的核心装置

## 二、乌吉恩发现了信号的真正含义

伊比尼伯龙的学生**乌吉恩**认为，那段讯息不是尼伯龙根发来的，而是来自某种星空生物。

他建造了：

- **乌吉恩生态圈**
- **星空生物捕捉站**

后来神秘信号再次出现，伊比尼伯龙之眼定位到了信号源，但目的地太远，飞船去了就无法返航。乌吉恩于是独自驾驶“望月者号”前往，并在星海中失踪。

几年后，飞船撞回捕捉站。玛歌洁蒂在里面发现了一只黑色球状生物。检测表明，乌吉恩的意识正在与这种生物融合。

乌吉恩主动与它融合，是为了突破语言障碍，将那段讯息带回龙族。讯息的内容大致是：

> 宇宙中正在蔓延漆黑的毁灭。  
> 收到警告的文明，应继续把它传递给下一个文明。

这很可能来自一个已经毁灭的文明，但龙族无法确认它究竟是不是最初的发信者。

乌吉恩传递完讯息后死去。后来玛歌尝试用古月力和黑体物质创造新的生命，制造出了巨大月灵“乌吉”，但乌吉恩的意识已经无法保留。

## 三、月幕工程与月亮武器化

玛歌继续完成丈夫未竟的事业，想把预警讯息发往宇宙。

与此同时，研究员**卢沙里姆**认为，向星空发信号太危险了，因为没人知道收到讯息的存在是否怀有善意。于是他研究出“幕形态黑体物质笼”，也就是**月幕**，试图遮蔽霜月、降低被外界发现的风险。

月幕工程分为两期：

1. 在乌吉恩圈进行小规模实验；
2. 建造足以遮蔽整个月亮的大型月幕。

但第二期工程即将完成时，来自天外的存在刺破了月幕，装置失控并爆炸。如今的**月荡海**，就是那场事故留下的遗迹。

之后，尼伯龙根从星海归来。他把霜月改造成了巨大的天基武器：

- 月心是月亮的生命本源；
- 月心不断提供古月之力；
- 这些力量可以从基地底部汇聚，作为射向提瓦特的“炮火”。

这就是旅行者和哥伦比娅在月亮背面基地里看到的真相。后来尼伯龙根败于天理，武器基地也失去了原本的作用。

## 四、宁宁是怎么诞生的

卢沙里姆不只想保存研究资料，还想把研究者们的情感、愿望和理想保存下来，让它们能够不断传承。

他收集了众多研究者的古月力信息，并借助月心的创生之力，创造了一个新的生命：

**宁希姬娅，昵称宁宁。**

宁宁被卢沙里姆当作女儿和学生抚养。她并不是普通的月灵，而是由：

- 月球本源的创生之力；
- 研究者们留下的信息；
- 霜月学者们的使命与愿望；

共同构成的“信息生命”。

卢沙里姆把“望月者计划”的最后一环交给了她。

## 五、现代剧情：旅行者重新走过这条路

在世界任务系列“望月”中，旅行者和哥伦比娅追查黑色月灵“黑蛋”的来历，依次探索：

1. **伊比尼伯龙之眼**
2. **乌吉恩圈**
3. **星空生物捕捉站**
4. **月幕实验所，也就是月荡海**
5. **月亮背面的龙族基地**
6. **月心**

黑蛋一路吞噬其他黑色月灵，逐渐获得更多信息，也慢慢想起自己的使命。

在月心，宁希姬娅留下的记录揭示了真相：

- 黑色月灵是月心创造出的新生命；
- 它们可能继承某位前辈的名字；
- 它们会通过互相吞噬来获得信息；
- 当使命变得清晰后，它们会重新走过前辈的道路；
- 最后以自身作为钥匙，开启伊比尼伯龙之眼的“望月者模块”。

也就是说，**黑蛋不是单独的一个生命，而是宁宁与所有霜月研究者共同留下的继承循环**。

这套循环已经执行过不止一次。

## 六、宁宁最后做了什么

哥伦比娅从月心取回了开启装置所需的古月力信息钥匙。旅行者一行回到望月者高塔后，宁宁得知：

> 自己的诞生，就是为了这一刻。

问题在于，向星空发送讯息可能暴露提瓦特，引来深渊或其他未知存在的注意。

哥伦比娅提出了一个降低风险的方法：

- 用月神之力包裹宁宁的讯息；
- 监测讯息穿过虚假之天后的情况；
- 如果发现危险，就在远距离抹除讯息。

最终，旅行者、哥伦比娅和派蒙决定支持宁宁再执行一次计划。

宁宁发出的讯息不是求救，而是对宇宙的回应：

> 在这片星空下，你们并不孤单。  
> 请继续向星空发出属于你们的声音。  
> 总有一束光，会成为刺破夜幕的曙光。

她最后以“伊比尼伯龙、乌吉恩、玛歌洁蒂、卢沙里姆、宁希姬娅”的名义，向所有可能听见的文明致意。

讯息发出后，宁宁完成使命并消失，只留下她的帽子。

## 七、结尾最大的伏笔

望月者模块启动后，伊比尼伯龙之眼意外解锁了一段尘封数据。

终端里传来了一个遥远文明的回讯：

- 对方说自己曾在宇宙中孤独穿行；
- 听见霜月传来的声音后，感到振奋与温暖；
- 他们希望未来寻找发信文明的星球；
- 但当时还有麻烦，暂时无法前往。

回讯最后出现了“哥哥”和“荧”的声音。

结合《龙族文明》的编年记述，这指向**旅行者兄妹在抵达提瓦特之前的星际旅途中，曾经收到过某个文明的预警讯息，并录下了回应**。游戏对白没有把全部时间线说死，但这明显是在暗示：旅行者兄妹早就在宇宙中参与过某次“望月者式”的星际通讯。

所以，“望月者计划”最后形成了一个闭环：

1. 一个文明发出灾厄警告；
2. 霜月龙族接收并继承；
3. 黑蛋一代代把讯息发往星空；
4. 某个遥远文明收到后回应；
5. 这段回应又被霜月保存下来；
6. 旅行者最终亲眼见证了这场跨越时代的通信。

## 一句话总结

**“望月者计划”讲的不是单纯的登月，而是霜月的学者们即使知道文明可能毁灭，也仍然选择把警告、勇气和希望传给宇宙中的下一个文明。**

## 可选社区依赖

BWiki 和 OBC 查询不需要任何额外依赖。只有查询**小红书 / 知乎 / B站**社区经验时才需要 **OpenCLI**——它是「npm 命令行 + Chrome 浏览器扩展」的组合，复用你已登录的浏览器读取页面（不需要 API Key，也不用粘贴 Cookie）。

想看玩家实战经验就推荐装上。可以自己装，也可以直接说「帮我装一下 OpenCLI」让派蒙代装或一步步指导（实际执行安装前都会先征得你同意）。**完整两步安装（含扩展的应用商店 / 离线两种装法）见 [skills/genshin-build-wiki/INSTALL.md](skills/genshin-build-wiki/INSTALL.md)。**

若 OpenCLI 已装但某个**平台能力**（`xiaohongshu/zhihu/bilibili` 平台子命令）为 `false`，只有在你**明确同意更新或修复**后，才会重装或升级。

不装时，skill 继续使用 BWiki + OBC，并明确说明没有覆盖社区经验。
